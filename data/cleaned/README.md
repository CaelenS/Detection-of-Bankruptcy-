# Cleaned bankruptcy datasets

Generated by `data_cleaning.ipynb` using the five ARFF files from the dataset stored in `data/raw/`.

Duplicate rows got removed, we only kept the first instance. 
Each year is split into roughly 70% training, 15% validation, and 15% test, stratified by bankruptcy class with seed 42.
Missing features were replaced with that year's training medians. Targets and observed values are unchanged. 

Each split CSV has 64 features and `bankrupt`. The companion row-ID CSV files show which of the original rows went in to each cleaned split
Training medians, summary tables, hashes, and software versions are included for reproducibility.

## File numbers and prediction horizons
Common source of confusion:
UCI describes the file numbers as years within the forecasting period, not years ahead.

| File | Years ahead |
|---|---:|
| 1year.arff | 5 |
| 2year.arff | 4 |
| 3year.arff | 3 |
| 4year.arff | 2 |
| 5year.arff | 1 |

Source: https://archive.ics.uci.edu/dataset/365/polish+companies+bankruptcy+data (Additional Information).


## Folder layout

- `1year/` through `5year/`: each contains its training, validation, and test CSVs.
- `supporting_records/`: original row IDs, training medians, summary tables, and cleaning metadata.
